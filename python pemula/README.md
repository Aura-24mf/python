# Python Pemula 🐍

Repository ini berisi kumpulan kode latihan dan dokumentasi pembelajaran **Python Pemula**. Setiap materi disusun secara bertahap mulai dari pengenalan dasar hingga penggunaan *virtual environment*.

## 📚 Daftar Materi

1. **Hello Python** (`hello.py`)
   Pengenalan sintaks dasar Python dan cara menampilkan output ke terminal.
2. **Variables and Data Types** (`variabel-data.py`)
   Penggunaan variabel serta tipe data dasar seperti `str`, `int`, `float`, dan `bool`.
3. **Operators** (`operators.py`)
   Penerapan operator aritmatika, perbandingan, dan logika dalam Python.
4. **If-Else Conditions** (`if-else.py`)
   Pengambilan keputusan dan percabangan alur program menggunakan `if`, `elif`, dan `else`.
5. **Loops** (`loops.py`)
   Perulangan program menggunakan `for` dan `while`.
6. **Lists and Dictionaries** (`lists-dictionaries.py`)
   Pengelolaan struktur data koleksi menggunakan `list` dan `dictionary`.
7. **Functions** (`functions.py`)
   Pembuatan dan pemanggilan fungsi untuk menyusun kode agar lebih modular.
8. **Classes and Objects** (`class-objek.py`)
   Dasar pemrograman berorientasi objek (OOP) dengan pembuatan `class` dan `object`.
9. **PIP and Virtual Environments**
   Manajemen paket eksternal menggunakan `pip` serta isolasi lingkungan proyek dengan `.venv`.
